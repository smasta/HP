## 執筆ルール（必ず守る）

1. **効果を断定しない。** 「転倒を予防できる」「認知機能が改善する」は景品表示法・
   薬機法に触れる恐れがある。「測定する」「可視化する」に留める。
   REAXION CARE の TAIS 登録は福祉用具であって医療機器ではない。
2. **出典を示す。** 制度・統計・ガイドラインに触れる記事は `sources` を必ず入れる。
   一次情報（厚生労働省、中央労働災害防止協会、国立長寿医療研究センター等）を優先する。
   - **URLは必ず curl で200が返ることを確認する。** 記憶で書かない。
     1本目の記事で、確認せずに書いた3件中2件が404だった。
   - **その制度が現行かを必ず確認する。** 廃止・改正されていないかを一次情報で確かめる。
     1本目の記事で、2026年4月1日に廃止された「エイジフレンドリーガイドライン」を
     現行として書いてしまった。法令の記述を誤ると信頼を大きく損なう。
   - 可能なら告示・指針の本文（PDF）まで読む。要約記事だけを根拠にしない。
3. **監修者を入れる。** 既定は下記。記事の内容に応じて変更が必要なら人手で差し替える。
   - name: 濱田 倫崇
   - role: 株式会社スマートスタート 認知機能研究所 所長
   - profile: 早稲田大学心理学専攻卒業。株式会社スマートスタート取締役COO、認知機能研究所所長。認知・身体・行動の測定手法の開発と、企業・介護・スポーツの現場への実装に携わる。
4. **日本語だけで書く。** 英語やその他の言語が紛れ込んでいないか、書いたあとに必ず確認する。
   固有名詞（REAXION、TAIS、LIFE 等）は除く。
5. **競合との差別化を意識する。** SERP調査の結果、競合は身体機能の測定に偏っており、
   認知・反応の視点が空白になっている。そこを主題に据える。
6. **h2 は4〜6本、本文は3,000〜5,000字程度。** FAQ は3〜5問、出典は2件以上。

### 指針の要点（記事を書く際の土台）

第2 事業者が講ずべき措置は5項目。
1. 安全衛生管理体制の確立等（経営トップの方針表明、リスクアセスメント）
2. 職場環境の改善（設備・装置、高年齢者の特性を考慮した作業管理）
3. 高年齢者の健康や体力の状況の把握（健康状況、体力の状況、情報の取扱い）
4. 健康や体力の状況に応じた対応（就業上の措置、業務のマッチング、健康保持増進）
5. 安全衛生教育（高年齢者向け、管理監督者向け）

**指針は考慮すべき特性として「筋力、バランス能力、敏捷性、全身持久力、感覚機能及び
認知機能の低下等」を列挙している。** 認知機能が明記されている点は、SMARTSTART の
主張を公式文書が裏付ける材料になる。体力チェックは「継続的に行うことが望ましい」で
あって義務ではない。

## 差別化の軸（調査で確認済み）

- 「高年齢労働者 安全配慮義務」は厚労省・中災防・SmartHR が上位。ヘッドは狙わない。
- 「高年齢労働者 体力チェック」の上位は小規模ドメイン（バリュスポ、アシストスーツの窓口、
  ロボタスネット）。測定項目は 2ステップテスト・片脚起立・柔軟性・筋力＝すべて身体機能。
- 「従業員 認知機能 測定」は認知症スクリーニング（のうKNOW、あたまの健康チェック）が占有。
  SMARTSTART は「事故を防ぐための反応・判断」＝労働安全の文脈で、直接競合しない。
- 「転倒リスク 評価 測定」は REAXION CLOUD が既に1ページ目。競合は StA²BLE。
